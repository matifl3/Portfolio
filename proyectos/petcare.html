PetCare — Veterinaria

Una aplicación para toda la clínica: mascotas, dueños, profesionales, turnos, historial clínico y tienda de productos — con tres roles de seguridad cuidando la puerta.

Rol Desarrollo fullstack — backend por capas, seguridad por roles y frontend en React.
Stack Spring Boot 4 · Java 21 · Spring Security · MySQL · React
Roles Administrador · Dueño · Profesional
Estado Desplegado y en línea · tp-vetcare-livid.vercel.app ↗

Qué gestiona esta clínica

Toda la operación de una veterinaria en una aplicación: usuarios con autenticación y roles, mascotas vinculadas a sus dueños con historial clínico completo, turnos con profesionales y una tienda de productos.

Qué construí

  • Usuarios con autenticación y seguridad por roles con Spring Security.
  • Registro de mascotas con historial clínico (vacunas y medicamentos).
  • Gestión de turnos con profesionales veterinarios.
  • Tienda de productos con carrito de compras y métodos de pago.
  • Estadísticas de ganancias y productos más vendidos.

Bajo el capó

  • Arquitectura por capas con DTOs en cada límite.
  • Validación y manejo de excepciones propias.
  • Java 21 sobre Spring Boot 4, modelo relacional en MySQL.
  • Frontend en React desplegado en Vercel.
