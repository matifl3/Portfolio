WEC — Pipeline ETL

ETL para normalizar y unificar los datos de cuatro temporadas del Campeonato Mundial de Resistencia (WEC), dejándolos limpios, estructurados y reutilizables para análisis.

Rol Diseño y desarrollo del pipeline completo, de la ingesta a la entrega del dashboard.
Stack Python · pandas · numpy · Looker Studio
Cifras 4 temporadas del WEC normalizadas y unificadas · Reportes automáticos de depuración de datos · Modelos limpios y estructurados listos para BI
Estado Entrega de trabajo — Informe técnico (PDF), exports limpios y dashboards en Looker Studio.

Qué procesa este pipeline

Cuatro temporadas del campeonato WEC con datos de cronometraje. El archivo crudo no sirve para analizar: hay que normalizarlo, validarlo y limpiarlo antes de confiar en cualquier gráfico.

Qué construí

  • Normalización y validación de datos de cronometraje de 4 temporadas.
  • Reportes automáticos de depuración de la información.
  • Exportación de modelos limpios para análisis posterior.
  • Dashboards interactivos en Looker Studio sobre los datos limpios.

Bajo el capó

  • Lógica ETL en Python con pandas y numpy.
  • Validación antes de visualizar: las filas malas se reportan, no se descartan en silencio.
  • Salidas limpias y documentadas, listas para BI.

El flujo

El pipeline, dibujado como corre: cronometraje crudo adentro, dashboard afuera.
